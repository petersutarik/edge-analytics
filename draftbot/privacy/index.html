Privacy Policy

draftbot

Last updated: April 11, 2026

draftbot is an internal, single-operator tool run locally on the operator's own machine. This policy describes what data the Tool touches and where that data goes.

1. Data draftbot Handles

TikTok OAuth tokens

When the operator authorizes draftbot via TikTok Login, the Tool receives and stores an access token, refresh token, and open_id in a local file on the operator's machine. These tokens are used solely to call the TikTok Content Posting API on the operator's own behalf.

Generated content

Text and images generated by AI providers are stored locally in the Tool's output directory on the operator's machine.

Prompts sent to AI providers

Topic prompts are sent to Anthropic (for text) and Google (for images) per their respective terms. draftbot does not send any TikTok user data — follower lists, audience data, private messages, or otherwise — to these providers.

2. Data draftbot Does Not Collect

  • No analytics, telemetry, or tracking of the operator
  • No third-party account data beyond the operator's own TikTok account
  • No audience, follower, engagement, or messaging data
  • No data is sent to any server operated by Edge Analytics

3. Data Sharing

draftbot does not share data with third parties beyond the API calls strictly necessary to function:

  • TikTok API — to push drafts to the operator's own account
  • Anthropic API — to generate text
  • Google AI API — to generate images

Each third-party service is governed by its own privacy policy.

4. Data Storage and Retention

All data handled by draftbot lives locally on the operator's machine. There is no cloud backend operated by Edge Analytics. The operator can delete any stored data at any time by removing local files.

5. Security

OAuth tokens and generated content are stored in local files. The operator is responsible for securing the machine draftbot runs on. draftbot does not transmit tokens or generated content to any server operated by Edge Analytics.

6. Your Rights (GDPR)

Because draftbot does not collect or store any data on servers operated by Edge Analytics, there is no user data under our control to access, correct, or delete beyond what is already stored locally on the operator's own machine. Requests relating to data held by third-party providers (TikTok, Anthropic, Google) should be directed to those providers.

7. Children's Privacy

draftbot is not directed at children under 13 and does not knowingly collect data from them.

8. Changes to This Policy

This Privacy Policy may be updated from time to time. The latest version always lives at this URL.
